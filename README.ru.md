# GitHub Actions Self-Hosted Runner Manager

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![PowerShell](https://img.shields.io/badge/PowerShell-5.1+-blue.svg)](https://github.com/PowerShell/PowerShell)
[![Platform](https://img.shields.io/badge/platform-Windows-lightgrey.svg)](https://www.microsoft.com/windows)

Универсальный менеджер для GitHub Actions self-hosted runners на Windows. Упрощает установку, настройку и управление раннерами для любого GitHub репозитория.

[🇬🇧 English version](README.md)

## ✨ Возможности

- 🔍 **Поиск репозиториев** - Поиск и выбор из ваших GitHub репозиториев через API
- 🔐 **Гибкое хранение токена** - Сохранение в переменной окружения, файле конфигурации или только в сессии
- 📋 **Интерактивное меню** - Удобный интерфейс с категоризированными опциями
- 🚀 **Автозапуск** - Настройка автоматического запуска раннера при загрузке Windows
- 🔄 **Авто-перезапуск** - Автоматический перезапуск при сбоях (3 попытки)
- 📊 **Мониторинг статуса** - Статус раннера и информация о конфигурации в реальном времени
- 📝 **Просмотр логов** - Просмотр последних логов раннера прямо из меню
- ✅ **Валидация токена** - Проверка GitHub токена перед сохранением
- 🎯 **Универсальность** - Работает с любым GitHub репозиторием (публичным или приватным)

## 🚀 Быстрый старт

### Требования

- Windows 10/11
- PowerShell 5.1 или выше
- GitHub Personal Access Token с правами `repo` и `workflow`
- Права администратора (только для функции автозапуска)

### Установка

1. **Клонируйте или скачайте репозиторий**
   ```powershell
   git clone https://github.com/ibuildrun/github-runner-manager.git
   cd github-runner-manager
   ```

2. **Запустите скрипт**
   ```powershell
   .\runner.ps1
   ```

3. **Настройте GitHub токен** (Опция 1)
   - Создайте токен: https://github.com/settings/tokens/new
   - Необходимые права: `repo`, `workflow`
   - Выберите метод хранения:
     - **Переменная окружения** - Постоянное хранение на уровне пользователя (рекомендуется)
     - **Файл конфигурации** - Локальное хранение, base64 кодирование
     - **Только сессия** - Не сохраняется, нужно вводить каждый раз

4. **Выберите репозиторий** (Опция 2)
   - Поиск по вашим репозиториям
   - Выберите репозиторий для подключения раннера

5. **Установите раннер** (Опция 3)
   - Скачивает и настраивает раннер
   - Регистрирует в выбранном репозитории

6. **Запустите раннер** (Опция 4)
   - Запускает раннер в фоновом режиме

## 📖 Использование

### Опции меню

#### Конфигурация
- **1. Настроить GitHub токен** - Настройка GitHub Personal Access Token с гибкими опциями хранения
- **2. Выбрать репозиторий** - Поиск и выбор репозитория через GitHub API

#### Управление раннером
- **3. Установить раннер** - Скачать и настроить GitHub Actions раннер
- **4. Запустить раннер** - Запустить раннер (фоновый режим или запланированная задача)
- **5. Остановить раннер** - Остановить все процессы раннера
- **6. Проверить статус** - Просмотр статуса установки и работы раннера
- **7. Просмотр логов** - Показать последние логи раннера (последние 50 строк)

#### Автозапуск
- **8. Включить автозапуск** - Настроить запуск раннера при загрузке Windows (требуются права администратора)
- **9. Отключить автозапуск** - Удалить настройку автозапуска (требуются права администратора)

#### Дополнительно
- **10. Удалить раннер** - Полностью удалить раннер (требуются права администратора)
- **11. Очистить конфигурацию** - Сбросить настройки репозитория и токена

## 🔐 Варианты хранения токена

### 1. Переменная окружения (Рекомендуется)
- Хранится в переменной окружения Windows `GITHUB_RUNNER_TOKEN` на уровне пользователя
- Сохраняется между сессиями и перезагрузками
- Доступна всем PowerShell сессиям
- Наиболее безопасный вариант для регулярного использования

**Просмотр токена:**
```powershell
$env:GITHUB_RUNNER_TOKEN
```

**Удаление токена:**
```powershell
[System.Environment]::SetEnvironmentVariable("GITHUB_RUNNER_TOKEN", $null, "User")
```

### 2. Файл конфигурации
- Хранится в `.runner-config.json` (base64 кодирование)
- Локально в директории скрипта
- Портативный вместе с проектом
- Примечание: Base64 это НЕ шифрование, только кодирование

### 3. Только сессия
- Не сохраняется нигде
- Нужно вводить токен каждый раз при запуске скрипта
- Наиболее безопасно для временного или одноразового использования

## 🐛 Решение проблем

### Ошибка валидации токена
- Проверьте, что токен имеет права `repo` и `workflow`
- Убедитесь, что токен не истек
- Проверьте, что токен для правильного GitHub аккаунта
- Попробуйте создать новый токен

### Поиск репозиториев не возвращает результатов
- Проверьте, что токен имеет доступ к репозиториям
- Проверьте правильность поискового запроса
- Попробуйте искать по части названия репозитория
- Убедитесь, что у вас есть хотя бы один репозиторий

### Раннер показывается как offline
- Проверьте, запущен ли процесс: `Get-Process -Name "Runner.Listener"`
- Просмотрите логи: Выберите опцию 7 в меню
- Перезапустите раннер: Остановите (опция 5), затем запустите (опция 4)
- Проверьте настройки репозитория на GitHub

### Автозапуск не работает
- Убедитесь, что запустили скрипт от имени администратора
- Проверьте запланированную задачу: `Get-ScheduledTask -TaskName "GitHub Runner - *"`
- Убедитесь, что задача включена и настроена на запуск при старте системы
- Проверьте логи задачи в Планировщике заданий

### Ошибка установки
- Проверьте, что GitHub токен имеет правильные права
- Проверьте подключение к интернету
- Убедитесь, что директория C:\actions-runner доступна
- Попробуйте запустить от имени администратора
- Проверьте настройки Windows Defender или антивируса

## 🔒 Заметки по безопасности

- Никогда не коммитьте `.runner-config.json` в систему контроля версий (уже в .gitignore)
- Хранение в переменной окружения более безопасно, чем в файле
- Токен проверяется перед сохранением
- Base64 кодирование это НЕ шифрование - используйте переменную окружения для лучшей безопасности
- Храните ваш GitHub токен в безопасности и регулярно обновляйте его
- Используйте токены с минимально необходимыми правами
